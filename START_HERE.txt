html_timetable_editor

Run: double-click START.bat (or: py -m http.server 8765) then open http://localhost:8765/index.html
This app has its own login page. On open it asks for a SCHOOL CODE first, then the login. Add schools in supabase-config.js (window.SCHOOLS).
See School_System_Guide.pdf for roles, password recovery and creating an admin.
